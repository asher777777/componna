# מודול קמפיינים ושגרירים (Ambassador Campaigns Hub)

<div dir="rtl" style="text-align: right; font-family: system-ui, -apple-system, sans-serif;">

מודול Full-Stack נייד ועצמאי לניהול קמפיינים של גיוס המונים, שגרירים, קהילות חכמות, סליקת תרומות ותזכורות וואטסאפ.

### תכונות מרכזיות:
1. **לוח התקדמות ויעדים (Campaign Header):** מד אחוזים, קצב גיוס, כמות תורמים, וקריאה לפעולה.
2. **הקמת שגריר (Ambassador Modal):** פתיחה מהירה של קהילה, מחולל סלאג ייחודי, קישור אישי ושיתוף מיידי בוואטסאפ.
3. **מגירת תרומות 4 שלבים (Donation Drawer):** בחירת מסלול (חד פעמי / הו"ק), פרטי תורם, הקדשות, וסליקה מאובטחת.
4. **עמוד מיקרו-פורטל לשגריר (Ambassador Landing Page):** עמוד ייעודי לכל מוביל קהילה עם יעד אישי ופיד תורמים משלו.
5. **סנכרון רוחבי ב-EventBus:**
   - הפצת אירועי שגריר חדש, תרומה ממתינה (סל נטוש), ותרומה מושלמת עבור `crm-analytics`, `whatsapp-green-api-hub`, ו-`crm-groups-hub`.
