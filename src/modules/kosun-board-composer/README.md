# KOSUN Board Composer (קושאן מחולל מערכות ולוחות בקרה AI)

רכיב מערכת מתקדם המאפשר חיבור של רכיבי האקוסיסטם של קושאן באמצעות AI (Google Gemini) לייצור מערכות ולוחות בקרה מותאמים אישית (Bento Grid 2026 Layout).
לוחות הבקרה שנוצרים ניתנים לשידוך מיידי לכל סאב-דומיין של משתמש (`subdomain.kosun.pro`), ומוצגים לו כלוח הבקרה הראשי בכניסה למערכת.

## עקרונות ויכולות ליבה

1. **זיהוי דינמי של כל רכיב במערכת (Requirement ב)**
   כל רכיב חדש שנרשם ב-`REGISTERED_MODULES` מקבל ביטוי מיידי ואוטומטי במחולל עם פעולות מהירות (Quick Actions), מדדי KPI מקושרים, וסנכרון לארכיטקטורת ה-AI.

2. **UI בלבד וסנכרון חי לקולקציות טננט (Requirement ג & ד)**
   - רכיב ממשק טהור ללא פגיעה בלוגיקה העסקית.
   - הווידג'טים מאזינים בזמן אמת (`onSnapshot`) לנתונים האמיתיים של המשתמש תחת `tenants/{tenantId}/{collectionName}`.

3. **שילוב מנוע ה-AI של Gemini (Requirement ה)**
   - קריאה ישירה למודלי `gemini-2.5-flash`, `gemini-3.8-flash`, ו-`gemini-2.5-pro`.
   - מפתחות ה-AI נמשכים ממרכז הניהול של המערכת (`SystemConnectionContext` / `DB Connector Hub UI`).

4. **תאימות מלאה למיתוג קושאן (Cashwan Branding)**
   - פריסת Bento Grid 2026 נקייה, מובייל פירסט.
   - תפריט עליון בלבד (Top Nav), ללא סיידברים.
   - פונט Heebo בלבד, אייקוני Lucide בלבד (ללא אימוג'ים).
   - טולטיפים עדינים (i) הנסגרים בלחיצה מחוצה להם.
   - נתונים סטטיסטיים משניים מוסתרים כברירת מחדל באקורדיון.
