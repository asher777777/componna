# מרכז השליטה והבקרה (Control Center Hub)

מודול לוח בקרה מרכזי בסטנדרט פרימיום לניהול, ניטור והפעלת כל רכיבי המערכת בממשק יוקרתי, ללא סיידבר, עם אפס נתוני דמה ו-5 סוגי פריסות מתקדמות.

## תכונות מפתח:
1. **אפס נתוני דמה (Zero Mock Data):** קריאה ישירה של ספירות וסטטוסים מקולקציות Firestore אמיתיות.
2. **5 סוגי פריסות:**
   - בנטו יוקרתי (Luxury Bento Grid)
   - מטריצת שליטה ורשימה מרוכזת (Command Matrix & Registry)
   - מדדים ניהוליים (Executive KPI View)
   - צינור תהליכים עסקי (Workflow Pipeline Stages)
   - סימולטור מובייל מלא עם מסגרת סמארטפון אינטראקטיבית בדסקטופ (iPhone / Android)
3. **בידוד מוחלט ללא ייבויי UI צולבים (חוק הספגטי):** שימוש בפונקציונליות וחוזים בלבד דרך `src/core/contracts/`.
4. **עצמאי לחלוטין וללא סיידבר:** מסך רחב, נקי ומרווח עם כפתור ניווט מהיר.
