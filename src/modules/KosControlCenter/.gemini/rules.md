# חוקי הפרויקט והבידוד לרכיב: Control Center Hub (`control-center-hub`)

1. **אפס ייבויי UI צולבים:** אין לייבא קומפוננטות UI ממודולים שכנים.
2. **אפס נתוני דמה:** אין לשתול נתוני Mock סטטיים או מדומים. כל הנתונים נקראים ישירות מ-Firestore.
3. **שימוש בחוזים:** אינטראקציה מתבצעת דרך `src/core/contracts/index.ts` ו-`collections.ts`.
4. **11 השכבות נשמרות בקפידה:** טיפוסים, קונפיגורציה, קונטקסט, הוקים, שירותים, API, פרומפטים, ניתובים, קומפוננטות, StandaloneView, ותיעוד.
