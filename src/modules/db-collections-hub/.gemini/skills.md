# db-collections-hub Skills & Domain Knowledge

## Available Skills & Procedures

### 1. Real-Time Document Inspection & CRUD
- Inspect collections, query documents by limit or index, and view real-time changes via Firestore snapshots.
- Create, edit, and delete JSON documents safely with client-side schema validation.

### 2. Multi-Tenant Collection Scoping
- Filter collection explorer views to display collections relevant to the active subdomain tenant (`tenants/{tenantId}/...`).
- Display collection statistics (document count, size, indexing status).

### 3. Collection Export & Backup
- Export document sets to JSON/CSV for tenant data mobility.
- Import structured records into tenant collections with duplicate key avoidance.
