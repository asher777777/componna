# סקילים ויכולות הרכיב: KoSeoPowerEngin

## 1. ניהול מפתח אחוד (Master Domain Key Management)
ניהול מפתח יחיד ל-Google Analytics 4 ו-Google Search Console ברמת דומיין האב (`kosun.pro`) עם חלחול אוטומטי לכל הדפים והסאב-דומיינים (`*.kosun.pro`).

## 2. אימות DNS ודפדפן בזמן אמת
בדיקת אימות רשומת DNS TXT ובדיקת נוכחות תגיות ב-DOM של הדפדפן.

## 3. ניטור מדדי חיפוש אורגני
מעקב חשיפות, קליקים, CTR ומיקום ממוצע בגוגל.
