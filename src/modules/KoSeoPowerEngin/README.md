# KoSeoPowerEngin - מנוע SEO, גוגל קונסול ואנליטיקס לדומיין וסאב-דומיינים

רכיב מודולרי עצמאי במערכת KOSUN26 לניהול אחוד של Google Analytics 4 ו-Google Search Console.

## יכולות מרכזיות:
- **עקרון המפתח האחד (One Key Master Connection):** הגדרת מפתח GA4 וקוד אימות Search Console פעם אחת ברמת הדומיין הראשי (`kosun.pro`), עם חלחול אוטומטי לכל הדפים והסאב-דומיינים (`*.kosun.pro`).
- **סנכרון עוגיות חוצות סאב-דומיין:** `cookie_domain: 'auto'` לשמירה על רצף סשן משתמש.
- **אימות DNS מהיר:** העתקת רשומת DNS TXT בקליק אחד לאימות מלא של נכס הדומיין ב-Google Search Console.
- **בדיקת אימות בדפדפן (DOM Inspector):** אימות חי של הזרקת תגית ה-meta והסקריפטים.
- **שיגור פינג בזמן אמת:** שליחת אירוע בדיקה ל-GA4 DebugView.
- **כרטיסי KPI ושאילתות חיפוש מובילות:** חשיפות, קליקים, CTR ומיקום ממוצע בגוגל.
