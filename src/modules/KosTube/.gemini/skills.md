# KosTube Skills & Operational Capabilities

## Core Skills
1. **YouTube Channel Synchronizer:**
   - Ingests channel details via YouTube handle (`@name`), URL, or Channel ID (`UC...`).
   - Retrieves video lists with metadata, duration, thumbnails, and descriptions.

2. **AI Video-to-SEO Transformer:**
   - Converts video transcripts or detailed video summaries into full-length structured articles.
   - Extracts key takeaways, executive summaries, and FAQs.

3. **SEO Analyzer & Schema Engine:**
   - Computes real-time SEO score (0-100) based on title, description, focus keywords density, and heading hierarchy.
   - Generates Google-compliant JSON-LD schemas (`VideoObject`, `Article`, `FAQPage`, `BreadcrumbList`).

4. **Public SEO Page Viewer:**
   - Fast, responsive, RTL-compliant public landing page for each video with embedded YouTube player and lead capture via `<CapabilitySlot name="form-renderer" />`.
