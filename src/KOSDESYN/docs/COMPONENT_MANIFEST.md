# 🗺️ מפת קומפוננטות UI - KOSUN2026 (UI Component Manifest)

מסמך זה מרכז את קומפוננטות הממשק עבור פרויקט **KOSUN2026**.
כל קומפוננטה מיועדת להיבנות באופן גמיש ודינמי ב-100%, ללא לוגיקה עסקית צמודה, עם פלייסהולדרים ושקעים (Slots / Props / Callbacks) מוכנים להלבשת נתונים ופונקציונליות מכל מקור (לרבות פרויקט CAMONA/COMONA).

---

## 🏗️ עקרונות ברזל בארכיטקטורת ה-UI

1. **זוג קבצים מחייב לכל קומפוננטה – תצוגה ועריכה:**
   * **קובץ תצוגה (`[Component]View.tsx`):** מרנדר את ה-UI של הרכיב לפי הגדרות הסכמה והעיצוב.
   * **קובץ עריכה (`[Component]Editor.tsx`):** פאנל / מודאל הגדרות ויזואלי המאפשר **לערוך כל אלמנט עיצובי** (צבעים, רקעים, טיפוגרפיה, ריווחים, אייקונים, שדות וסדר תצוגה).
2. **בידוד מוחלט (Pure Presentation):** הרכיבים אינם מייבאים ישירות בסיסי נתונים, ספריות צד-שרת או ספריות AI מקומיות. כל נתון, סגנון עיצובי, פעולה או אירוע מוזרק מבחוץ דרך Props / Schema.
3. **הלבשה מלאה (Pluggable Schema & Design Config):** קומפוננטה מרנדרת את עצמה לפי סכמה דינמית של תוכן (Content Schema) וסכמה דינמית של עיצוב (Design System Config).
4. **תאימות RTL ועברית מלאה:** עיצוב מותאם מימין לשמאל, טיפוגרפיה ברורה ואיפוק ויזואלי מקצועי (אייקוני Lucide אלגנטיים, ללא אימוג'ים בממשק הרשמי).
5. **תאימות לחוקי KOSUN26:** שימוש ב-Floating Dock, מודאלים במסך מלא (Fullscreen Modals), והיעדר Header עליון כבד ומקובע במסכי הליבה.

---

## 🛠️ מבנה הקבצים המחייב לכל קומפוננטה ב-`kosontime/KOSUN2026/`

לכל קומפוננטה נבנה צמד קבצים ברור – **תצוגה (View)** ו**עריכה (Editor)**, לצד הגדרות הטיפוסים והסכמה:

```text
kosontime/KOSUN2026/
├── COMPONENT_MANIFEST.md        <-- הקובץ הנוכחי למעקב ועקרונות
├── components/                  <-- קומפוננטות ה-UI
│   └── [component-name]/
│       ├── [ComponentName]View.tsx      # 1. קובץ התצוגה (Pure UI / Presentation)
│       ├── [ComponentName]Editor.tsx    # 2. קובץ העריכה (Visual Customizer לכל אלמנט עיצובי)
│       ├── [ComponentName]Adapter.tsx   # מתאם אופציונלי להלבשת Firestore/CAMONA
│       ├── types.ts                     # סכמת נתונים, שקעים (Slots) והגדרות עיצוב (StyleProps)
│       └── index.ts                     # שער ייצוא רשמי
├── preview/                             <-- סביבת הרצה ובדיקה מול נתוני אמת מ-COMONA
│   └── ViewComponaScreen.tsx
└── index.ts                             <-- שער ייצוא גלובלי
```

---

## 🎨 מה כולל קובץ העריכה (`[Component]Editor.tsx`)?
קובץ העריכה נותן מענה לדרישה ש**כל אלמנט עיצובי מקבל אפשרות עריכה**:
* **צבעים וערכות נושא:** צבע ראשי, צבעי טקסט, רקע, מסגרות, מצבי Hover ו-Active.
* **טיפוגרפיה:** גודל גופן, משקל, יישור וכותרות.
* **ריווחים ומבנה:** Padding, Margin, רדיוס פינות (Border Radius), צלליות (Box Shadow).
* **ניהול פריטים ותוכן:** הוספה/מחיקה/עריכה של כפתורים, קישורים, אייקונים וטקסטים.
* **התאמה אישית:** Live Preview בזמן אמת של השינויים עוד לפני השמירה.
