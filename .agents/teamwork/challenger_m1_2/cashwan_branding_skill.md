# המיתוג של קושאן (Cashwan Branding)
Source: C:\Users\ovt57\.gemini\config\skills\cashwan-branding\SKILL.md

1. קושאן כיישות חיה ונושמת:
- באנגלית: תמיד KOSUN באותיות גדולות (למשל KOSUN AM).
- בעברית: תמיד קושאן (למשל קושאן מייל אוטומטי).
- טון דיבור: שותף אישי שלוקח אחריות ("קושאן דואג...", "קושאן מכין...").

2. מובייל פירסט, פריסה ומינימליזם 2026:
- Mobile First
- מינימום נתונים, מקסימום פונקציונליות, אוויר (Negative Space), פירוט יתר במודאלים.
- Bento Grid Layout (כרטיסיות מעוגלות, נקיות, שטוחות).
- ניווט: אין להשתמש בתפריטי צד (Sidebars / Sliders). Top Navigation בלבד!

3. שפת הממשק, טולטיפים וטיפוגרפיה:
- גופן בלעדי: Heebo.
- טולטיפים חכמים (i) מזעריים במקום טקסט ארוך, נסגרים בלחיצה בכל מקום וב-x.
- ללא כותרות ענק.
- כפתורים: קצר, מניע לפעולה, צעיר וברור.

4. מצב יום / לילה וקונטרסט:
- Light Mode ברירת מחדל, תמיכה ב-Dark Mode.
- ניגודיות גבוהה.

5. שמירת מזהים ולוגיקה:
- שמירת id, className, data-*.

6. נתונים וסטטיסטיקות:
- הסתרת נתונים סטטיסטיים / Stats Cards כברירת מחדל תחת אקורדיון / לשונית נפתחת (Collapsible).

7. איסור מוחלט על אימוג'י טקסטואליים:
- אפס אימוג'ים (👋, 📞, 💰, 🤖 וכו') בממשק, בדיפולטים או בסימולטורים.
- שימוש בלעדי ב-Lucide Icons.
