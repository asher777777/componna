# המיתוג של קושאן (Cashwan Branding) - Local Copy

1. קושאן כיישות חיה ונושמת (The Entity of Kosun):
   - באנגלית: תמיד KOSUN באותיות גדולות (למשל: KOSUN AM).
   - בעברית: תמיד קושאן (למשל: "קושאן מייל אוטומטי", "קושאן דואג לך").
   - שפה של שותף אישי שלוקח אחריות ("קושאן דואג", "קושאן מכין").
2. מובייל פירסט, פריסה ומינימליזם 2026:
   - Bento Grid Layout עם כרטיסיות נקיות ופינות מעוגלות.
   - ללא Sidebars: Top Nav בלבד.
3. שפת הממשק, טולטיפים וטיפוגרפיה:
   - גופן Heebo בלבד.
   - טולטיפים חכמים (i) מזעריים.
   - אפס אימוג'ים טקסטואליים - אך ורק Lucide icons.
4. עטיפת RTL מלאה: <div dir="rtl" style="text-align: right;">.
5. הצגת נתונים וסטטיסטיקות: נתונים משניים מוסתרים באקורדיון מתקפל כברירת מחדל.
